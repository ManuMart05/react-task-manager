# 📝 Task Manager – React

A modern, responsive task management application built with **React** and **Vite**.  
The app allows users to create, complete, and delete tasks with persistent storage and a clean, modern UI.

## ✨ Features

- ✅ Add and delete tasks
- 🔁 Persistent data using `localStorage`
- ☑️ Mark tasks as completed
- 🌙 Light / Dark mode with theme persistence
- 📱 Fully responsive (mobile-first)
- ✨ Subtle animations for a modern feel

---

## 🛠️ Built With

- **React** – UI library
- **Vite** – Fast development & build tool
- **JavaScript (ES6+)**
- **CSS3** – Custom, modern styling
- **LocalStorage API**
